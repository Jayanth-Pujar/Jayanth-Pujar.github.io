01 / ABOUT

How I work

I work mostly in SQL — joins, CTEs, window functions — to trace patterns across transaction and user data, then build Power BI dashboards with Power Query and DAX so the fraud team can act on what I find without reading a query themselves. Python (Pandas, NumPy) handles the analysis layer in between.

At Flipkart, that meant investigating patterns like repeated purchases, suspicious shipping-address clusters, and payment mismatches — then validating the numbers before they went in front of stakeholders. I'm comfortable owning a metric from raw data to the dashboard a business owner actually looks at.
